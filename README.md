 ## Recauva - Official Physiotherapy Website

Welcome to **Reccova**, a dynamic and beautifully animated physiotherapy website designed to offer seamless service booking, medical information, and patient engagement with a soothing user experience.

 **Live Website:** [www.recauva.com](https://www.recauva.com/)

---
 Project Highlights

-  **Elegant UI:** Soft white theme with gentle green, violet, and soft pink gradients.
-  **Smooth Animations:** Modern, responsive design with Tailwind CSS and Vercel v0.dev animations.
-  **Authentication:** Secure login/signup flow for patients and staff.
-  **Booking System:** Dynamic service booking with live availability and confirmation.
-  **Service Pages:** Interactive sections with detailed physiotherapy service information.
-  **User Navigation:** Clear, fast-loading UI with intelligent routing and active state transitions.
